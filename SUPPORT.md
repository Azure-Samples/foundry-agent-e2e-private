# Support

This sample is provided as-is under the [MIT license](LICENSE). It is not a
production reference architecture and does not include a support SLA.

For sample bugs, documentation issues, and questions, use
[GitHub issues](https://github.com/Azure-Samples/foundry-agent-e2e-private/issues).
Include the steps to reproduce, expected and actual behavior, tool versions,
and sanitized error messages. Do not post credentials, deployment outputs,
subscription identifiers, or customer data.

For Azure service incidents or subscription-specific problems, use
[Azure support](https://azure.microsoft.com/support/options/).
Report suspected vulnerabilities privately through [SECURITY.md](SECURITY.md).
